Connect Your Google Sheet

The dashboard reads live fellow activity from the same Google Sheet your companion site already writes to. You need to add one function to your existing Apps Script so it can also return data on request.

  1. Open your Google Sheet: Extensions → Apps Script
  2. You'll see your existing doPost(e) function. Add the doGet(e) function below in the same script file.
  3. Click Deploy → Manage Deployments, then click the pencil icon on your existing deployment.
  4. Set Version to "New version" and click Deploy. The URL stays the same — no changes needed here.

Paste this function into your Apps Script (alongside your existing doPost):

function doGet(e) {
  try {
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheet = ss.getActiveSheet();
    var data = sheet.getDataRange().getValues();
    if (data.length < 2) {
      return ContentService
        .createTextOutput(JSON.stringify({ status: 'ok', data: [] }))
        .setMimeType(ContentService.MimeType.JSON);
    }
    var headers = data[0];
    var rows = data.slice(1).map(function(row) {
      var obj = {};
      headers.forEach(function(h, i) { obj[h] = row[i]; });
      return obj;
    });
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok', data: rows }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error', message: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

After redeploying, click ↻ Refresh in the dashboard topbar. Fellow activity will appear automatically.
